# Bookstamp logo kit: Oswald, subtle tilt

Mark: 04 V3 B-edge stamp, tilted −1.2°. Wordmark: Oswald SemiBold caps, 0.06em letterspacing, converted to outlines.

## Folders
- icon/: tilted mark for 24 px and up (SVG + 512 PNG)
- icon/small-straight/: straight mark for 16–23 px
- single-line/: mark and wordmark side by side (SVG + 4x PNG)
- two-line/: bookstamp-stacked-oswald-* is centered; bookstamp-stacked-left-oswald-* is left aligned
- favicon/: ico, svg and the 16/32 PNGs are straight; apple-touch-icon and icon-192/512 are tilted

## Colorways
- color: ink #26221C + stamp violet #2F2A63
- violet: one color #2F2A63, mark at 85% opacity
- ink: one color #26221C
- paper: one color #EFE3C6, for dark grounds
